# ShrinkBomb

A Fabric mod for Minecraft 1.21 that adds a custom shrinking bomb mechanic.

## Features
- Custom bomb with shrinking mechanics
- Unbreakable glass containment box (25x25x25 blocks)
- Dynamic scaling system
- Emerald-triggered release mechanism

## Installation

1. Install Fabric Loader
2. Place the mod JAR in your `mods` folder
3. Launch the game

## Building

```bash
./gradlew build
```

The built JAR will be in `build/libs/`
